Não implantar Rules para testar se o cliente “continua funcionando”. Não relaxar segurança, fabricar permissões/baselines ou executar migração real. Backup protegido/completo, restauração isolada e rollback coordenado precisam ser comprovados antes de qualquer release no ambiente existente. O deployment estático separado não altera esta conclusão.
